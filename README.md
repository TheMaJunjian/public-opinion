# 公论

通过消息发言、举证、组织讨论、表态和结算。分类、关系、显示方案与规则提案都由消息表达。

## 运行

需要 Node.js 24。

```sh
npm ci
npm run dev
```

打开 http://localhost:5173。API 默认使用 3000 端口，SQLite 数据保存在 `data/gonglun.sqlite`。本地首次注册建立项目发起人账户，其他注册账户为普通参与者。

```sh
npm test
npm run build
npm start
```

构建后访问 http://localhost:3000，同一服务提供页面与 API。部署方式见 [部署说明](deploy/README.md)。

## 代码

- `packages/core`：消息部件、稳定引用、版本与显示投影。
- `apps/server`：账户、事务账本、规则执行、分页查询和增量同步。
- `apps/web`：讨论界面、消息编辑器、引用检查器及客户端同步。
- `docs/公论第一版规范.md`：功能与规则。

每条关系中的成员具有独立 ID。引用可定位消息、版本、部件、成员、成员中的引用值或文本范围。组织成员保持唯一直接归属，可嵌套；显示变化不会复制消息身份。

发言默认仅支付协议费，推荐投入和对赌金额由发送者分别选择。单边结算退还赌注；双方对赌按金额判胜；分配、处罚、平反和修改授权保留公开消息及记录。充值申请经发起人确认入账。

客户端以分页获取所需消息，通过连续序号接收变更。发送请求带幂等编号，重试不重复扣费。消息、资金变动和变更记录在同一事务提交。
