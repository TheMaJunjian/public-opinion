# 公论说明与文档导航

## 当前定位与运营原则

- 公论是争论、辩论和线上文字开会的工具。“游戏”用于解释博弈与激励机制。
- 保留宣传主张：“公论中有：发言投票（权），胜利的一方获得贡献点（钱），给所有人留下被认可的信息（真理）。”
- 用公论运营公论：一切运营由公论用户负责，所有运营信息在公论上公开。招合伙人，条件不限；线上运营，信息公开；投票结算，按功分配。
- 贡献点是对公论贡献的计量，先解释使用、判断、建设、运营和资金等贡献，再说明当前计时、到账确认、认定与发放机制。
- 公开透明是原则。当前系统中心化运行，透明中心与去中心化仍在比较，独立节点和上链按实际需要评估。

介绍与推广保留立场、情绪和共建邀请，讲清楚为什么值得参与；功能与规则文档准确说明当前如何操作。已有能力、运营原则和待定技术路线分别标明，宣传中的“权、钱、真理”无需统一改写成中性的功能摘要。
