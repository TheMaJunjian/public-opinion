——
我不确定我是不是疯了，我看普通人都像是人机。阅读理解能力完全不合格。
所谓公开隐私的隐私，是来自我提出的不可能三角中的人性、公平、隐私。在不违反人性的情况下，追求公平要公开隐私，但实际上实行起来只是提供一个大多数区域装摄像头监控的公共场合而已，然后由大家自愿，是否愿来经历无需工作的生活。
卧室浴室不属于公共场合，我的办公室属于是公共场合，所以大家能看到公司的筹备和运营全过程。
竟然有人因为救世主这个公司名称就说是邪教……笑死，邪教才能挣几个钱。
化腾免费让人玩游戏，还送皮肤，亏成了首富。
军健免费给人提供基础生活保障，会亏成什么？
自提出那一刻起，公司已经锁定了世界500强的首席。
很多人意识不到，价值和统战价值以外，人的本身就有存在价值。
公司的可行性可以简单抽象成一句话：
公司成员在公共场合开放透明所带来的互相信任与通力合作，值不值得付出包括公司成员基础生活保障支出在内的公司运营成本？
答案是值得。
零氪玩家作为背景板可以获得氪金玩家的供养，免费玩游戏。
对应到现实，比如地级成员享受的基础保障提供的服装是穿起来舒服但外观简单的衣服；天级可以自己买衣服随便穿；玄级给公司充钱有指定款式的衣服穿。7
在游戏里充钱可以在游戏里当大佬，在现实里充钱，在现实里当大佬。
这个逻辑有问题吗？
把现实当做游戏来运营，公司解决了现实没有充值入口的bug。
这就是“贡献决定地位，金钱换取权力”。
这就是“透明换取自由，游戏降临现实”。
能听懂吗，各位？
