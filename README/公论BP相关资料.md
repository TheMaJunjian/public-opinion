Polymarket 和“公论”虽然都涉及“押注”和“结果”，但从底层设计到最终导向，完全是两套逻辑：

第一，核心目的不同：投机 vs 生产。
Polymarket 是一个金融投机工具，它的生命始于事件开始，终于事件结束——比如特朗普能否当选，大选结果一出来，合约结算完毕，所有信息立刻归零，对后续再无任何指导价值。而“公论”是一个知识协作平台，它的生命始于讨论、终于无限延续——比如大家讨论某商品是不是316不锈钢，一旦达成共识，这个结论会永久存证，成为可供任何人随时调取的知识库部件。几年后有人想买同款商品，依然能查到当时的测评记录和结论，持续产生指导作用。

第二，纠错机制不同：一次定音 vs 持续可推翻。
在 Polymarket，事件结束后一切锁死。而在公论中，结论不是一劳永逸的——如果这一批货是不锈钢，下一批不是，那么买到假货的用户就可以通过举证推翻之前的结算，直接赚取商家的押注。这就意味着，公论的每个结论都随时接受新证据的挑战，信息的真实性和时效性由市场持续检验。

第三，商家押注的逻辑：自我增信，倒逼改进。
商家为什么要押注自己的商品？答案很简单——如果连商家自己都不信任自己的产品，不敢为之押注，那别人凭什么信任？ 商家通过押注向市场传递信心，而这份押注同时也是一份“质量保证金”——一旦被证伪，直接损失筹码，所以商家必须在押注前就确保产品经得起考验，从而倒逼自己持续改进质量。

第四，对“错误”的激励导向：说假话必然亏钱。
在 Polymarket，押错方向只是损失本金，结果确定后无需承担任何责任。而在公论里，一个人不可能在所有时间欺骗所有人——任何虚假言论一旦被揭穿，纠正者就能通过提供正确信息来赚取押错者的筹码，说假话一定会产生可量化的、真金白银的损失。公论不是靠道德呼吁维持秩序，而是靠“他人有足够的利益动力来揭穿你”来倒逼诚实。

第五，正反馈循环：错误是燃料，而非沉默成本。
Polymarket 是零和博弈——有人赢就有人输，总价值不变。公论是正和博弈——每一次纠正错误都在为社区积累有价值的信息，每一次纠偏的路径都被记录，成为后来者的参考。错误不再是沉默的成本，而是推动共识进化的燃料。

发送文本消息：

在输入框输入内容 → 点击发送

- 说明：消息附带 PRO （赞同）自押（最少10点）+ 1点手续费



发送关系消息：

选择关系类型（赞同/反对/标注/回复/引用/注释等等）；

单击选择消息，消息进入候选区，点击加入来源集合按钮将候选区中的消息作为来源消息；

单击选择消息，消息进入候选区，点击加入目标集合按钮将候选区中的消息作为目标消息

点击发送按钮（发送前可以修改贡献点，发送后可通过赞同或投票追加）



- 说明：消息附带 PRO （赞同）自押+ 1点手续费

- 说明：赞同某个消息可以点击这个消息，关系类型选择赞同，点击发送

- 说明：有些关系消息不需要来源消息或目标消息，比如赞同消息，不需要来源消息

- 说明：输入框中存在文本时，候选区非空，点击发送按钮，为发送关系消息的快捷方式：会将输入框中的文本新建文本消息并作为来源集合，候选区消息作为目标消息

- 说明：关系类型中有提案消息，可以发起提案，分配包括手续费、充值收入、运营收入



结算：

消息卡上有结算入口，可以点击投票或发起结算，一点贡献点一票，多数获胜，胜方按投票比例分配败方贡献点。

结算结果可推翻，所有相关贡献点根据投票结果重新分配
