# 公论宣传口播稿（5分钟完整版）

大家好，我想认真介绍一款我正在做、也非常希望大家一起共建的开源游戏：公论。

先说一句最核心的话：
公论不是“开会模拟器”，而是真的开会。

为什么我要强调这一点？
因为今天的大多数聊天和讨论工具，依然停留在“线性消息流”时代。
大家在同一个群里同时聊多个问题，很快就会互相覆盖；
只要少数人连续输出，就能造成刷屏；
真正有价值的消息和噪音消息在界面上几乎等权；
讨论过后，常常只能留下情绪，留不下可复查的结论。

公论想做的事情，是把讨论从“噪音流”，升级为“结构化协作系统”。

在公论里，每一次发言、表态、举证、投票，都会成为可追踪、可结算、可复查的公共记录。
支持、反对、引用、补充、反驳这些关系，不再藏在上下文里，而是被清晰表达、持续追踪。

这样做的意义是：
我不是在比谁嗓门更大，
也不是在比谁话术更强，
而是在公开规则下，让结论可以形成，也可以被后续挑战。

公论中的“共识”不是绝对真理，
而是可审计、可翻案、可迭代的阶段性结果。

接下来讲大家最关心的一点：
公论中的货币和积分，统一叫贡献点。

贡献点不是装饰品。
它是你在系统里表达立场、参与治理、推动结算的工作凭证。
你可以消耗贡献点，也可以获得贡献点。

这背后有一个非常关键的变化：
在传统平台模式里，创作者生产内容，与会者贡献注意力，平台主导收益分配。

在公论里，与会者不只是“流量”。
与会者通过识别信息价值、筛选有效观点、推动共识形成，参与真实价值创造。
因此，与会者应该参与分配。

换句话说，
谁在认真判断信息，谁就在做有价值的工作。
这份工作应该有回报。

再说去中心化。
很多人一听去中心化，第一反应是匿名。
公论不是这条路。

公论走的是：
不是通过匿名对抗审查，
而是通过公开监督审查。

在这里，审查不该是黑箱权力，
而应当是公开流程本身。
规则可以被讨论，结论可以被挑战，历史可以被回看。
任何有影响的判断，都应该留下责任路径。

这就是公论强调“公共场合”而不是“私密黑箱”的原因。

很多人还会问：
既然你叫它游戏，为什么又这么严肃？

因为我承认现实。
公论是免费游戏，但要长期运行，必须有资源。
资源来自运营收入和与会者充值。

充值后，与会者会有更多贡献点，
可以购买特权，比如更高的展示优先级、更丰富的展示样式、更好的体验能力。

我不回避这一点：
公论需要氪金与会者。

但同样重要的是，
零氪与会者不该只是“白嫖者”，
而应该从参与中获得收益。

因为一个公共讨论系统的价值，不只来自头部发言者，
还来自大量参与者对信息生态的共同塑造。
跑龙套、当背景板、提供判断样本，本身就是贡献。
贡献就应该有回报。

现在说项目状态。

公论已经有基础功能版，
但距离完整形态还有很多工作。
如果只靠我一个人推进，速度会非常慢。

而这件事每早一天完善、每早一天投入使用，
人类就能更早拥有一套更可靠的公共讨论基础设施。

所以我选择现在就公开，邀请共建。

我会坚持三件事：
第一，开源协作，规则公开；
第二，过程可追踪，结论可复查；
第三，所有贡献都会被记录，并在项目规模化后兑现对应收益。

最后，我想邀请这几类人加入：

如果你厌倦了无效争吵，
如果你不想再被噪音流裹挟，
如果你相信“信息价值应该被定价，判断能力应该有回报”，
如果你愿意参与一套把制度、技术与协作放在一起打磨的系统，
那么，欢迎你参与公论。

你可以是开发者、设计师、产品、运营，
也可以只是一个愿意认真讨论、愿意承担判断责任的人。

公论不是一个已经完成的答案。
公论是一套正在被共同构建的问题解决机制。

今天加入，
不是为了围观一个项目，
而是为了参与定义一种新的协作秩序。

公论，欢迎你来共建。
