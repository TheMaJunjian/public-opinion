# 公论宣传口播稿（60秒版）

大家好，我想给你介绍一款开源游戏：公论。

它的内容不是“开会模拟器”，而是真的开会。
在这里，发言、表态、举证、投票，不再是刷屏，而是可追踪、可结算、可复查的公共记录。

公论里，货币和积分统一叫贡献点。
你可以消耗贡献点表达立场，也可以通过高质量参与获得贡献点。
并且，贡献点预留了与现实货币自由兑换的能力。

我想解决的是：
今天的聊天工具，结构太原始。
多问题无法并行讨论，少数人刷屏就能淹没有价值的信息，观点链条断裂，责任无法追踪。

公论给出的答案是：
把讨论变成结构化协作。
支持、反对、引用、反驳都可见；
结论可挑战、可推翻、可审计。

公论的去中心化，不靠匿名躲避审查，
而是靠公开来监督审查。
公论不是躲审查，公论就是把审查变成公开机制。

我已经公开基础功能版，正在邀请共建。
所有贡献都会被记录，项目成熟后，贡献者会获得与贡献对应的收益。

如果你厌倦无效争吵，
如果你相信信息价值应该被定价，
如果你愿意参与一套真正能改善公共讨论秩序的系统，
欢迎加入公论，一起把它做出来。
