# 公论：把“开会”做成一场真实可结算的公共游戏

大家好，给大家介绍一款开源游戏：公论。

公论是楚门计划的一片拼图，它的玩法很简单，也很反常识：
不是“开会模拟器”，而是真的开会；
不是“聊天换皮”，而是把每一次发言、表态、举证、投票，变成可追踪、可结算、可复查的公共记录。

在公论里，货币和积分统一叫“贡献点”。
贡献点可以消耗，也可以获得；
可以用于表达立场、参与讨论、推动结算、参与治理；
并且预留了与现实货币自由兑换的能力。

一句话：
公论不是让你围观讨论，而是让你为自己的判断下注，并为结果负责。

## 公论要解决什么问题

今天的大多数聊天和讨论工具，结构还停留在“线性刷屏”时代：

- 多个问题无法并行讨论，信息互相覆盖。
- 少数活跃与会者就能制造刷屏，真正有价值的内容被淹没。
- 回复链条断裂，观点上下文丢失，责任无法追踪。
- 有价值信息和噪音信息在界面上几乎等权显示。

公论的目标，是把“讨论”从噪音流，升级为结构化协作：

- 消息之间的关系可见：支持、反对、引用、补充、反驳都可追踪。
- 观点可以被持续挑战，不靠身份压人，靠公开规则推进共识。
- 结论不是“谁嗓门大谁赢”，而是可复算、可推翻、可审计的暂时共识。

## 公论为什么说自己去中心化

很多项目讲去中心化，首先想到匿名。
公论不是。

公论走的是另一条路：
不是通过匿名对抗审查，而是通过公开监督审查。

在这里，审查不是黑箱权力，而是公开流程本身。
规则可以被讨论，结论可以被挑战，历史可以被回看。
公论不是躲避审查，公论就是把审查变成所有人都能参与、都能复查的公共机制。

## 隐私、真实性与信息价值

隐私是黑暗的基石，公论是公共场合。

在公论上发布测评、阅读测评，不需要盲信“平台背书”。
你可以公开站队、公开举证、公开质押。
不真实的信息发送者，不再只是“被口头反驳”，而是要为错误信息承担可见成本。

我不是在追求“永远正确”，
我追求的是：
让每一次错误都能被定位，让每一次纠偏都有路径，让每一份价值都能被记录。

## 公论的贡献点系统

公论提供一种可执行的方法：
用制度筛选有价值的信息，
再用有价值的信息，反过来完善制度。

这也是贡献点系统的意义：

- 发言不是免费噪音，可以消耗贡献点。
- 高质量参与不是情怀劳动，可以获得贡献点。
- 与会者不仅消费内容，也参与收益分配。

传统商业模式是：
创作者生产内容，与会者贡献注意力，平台主导分配。

公论希望做的调整是：
分配由与会者共同决定，并将部分收益分配给与会者。
因为与会者在做真正的价值工作：识别信息价值、筛选有效观点、推动共识形成。

## 为什么公论是“免费游戏”，但仍然需要氪金

公论要长期运行，需要真实资源。
资源来自运营收入和与会者充值。

充值后，与会者会有更多贡献点，
可以购买特权，例如更高的排行榜位置、更好的展示样式、更多高级功能体验。

这不是回避现实，而是承认现实。
公论需要氪金与会者。

但同样重要的是：
零氪与会者不该只是“免费体验者”，
还应当从参与中获得收益。

跑龙套、当背景板、提供讨论生态、贡献判断样本，
这些都是真实贡献，都应有真实回报。
