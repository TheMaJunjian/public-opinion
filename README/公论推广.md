# 公论推广

**讨论、投票、结算，线上文字开会。**

拿出你的证据，为你的判断下注。让不同问题各自展开，让后来的人接着检验和讨论。

**公论中有：发言投票（权），胜利的一方获得贡献点（钱），给所有人留下被认可的信息（真理）。**

## 怎样让争论有结果

- **发言与举证**：回复、引用、注释、提问和回答可连接消息或片段；分类、归并、总结和排列帮助整理讨论。
- **表态与投票**：赞同、反对判断真假，推荐、冷藏评价价值，按押注点数计算权重。
- **结算与翻案**：新的证据可以推动后续轮次，撤回旧分配并重新计算，保留调整记录。

## 贡献点从哪里来

**贡献点是对公论贡献的计量。** 使用与关注、判断和整理信息、开发设计、推广运营，以及资金与资源支持，都应有记录与认定办法。

新账户从 0 点开始，登录后保持网页运行，即可按计时规则积累使用贡献，无需预先充值。确认到账的充值记录资金贡献；开发、设计、推广与运营等工作，经公开认定及授权发放贡献点，逐类自动计量仍在完善。

贡献点用于发言与投票。结算收益来自参与者的押注：胜方收回本金，并按投入比例分得败方本金；平局或单边押注时退还本金。
