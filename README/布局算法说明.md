# 非线性显示

`frontend/src/components/GraphView.tsx` 根据消息、关系和已生效状态生成显示，再由纯布局函数计算位置。

- `stanceLayout.ts` 按执行时解析的目标划分讨论区，赞同、目标、反对分列；保留原关系链供追溯。
- `frameLayout.ts` 从内向外计算组织尺寸，再从外向内放置。嵌套组织只测量和放置一次，循环引用不能造成无限递归。
- `useCardMeasurements.ts` 用稳定的 ResizeObserver 汇集真实卡片尺寸，尺寸不变时不触发布局更新。
- 分类、总结、归并、排列使用同一消息身份；当前被取消的覆盖效果恢复原消息，组织声明及历史仍可查看。
- 卡片默认宽度为 320；用户名显示字符数不超过消息 ID（省略号计入长度），悬停可看全名。表头按实际字体测量所需空间，ID 放不下时自动增宽；卡宽变化只改变列的横向间距，不通过像素反推逻辑列。
- 更正的附加关系依次为“宽度调整、修正文字、修改原意”。宽度调整选择一条当前完整消息，可输入 320–2400 的整数、拖动滑块或卡片右边缘；拖动按画布缩放比例换算，双击手柄恢复默认，发送前仅预览。发送后作为 `CORRECT / WIDTH` 记录保存，按本人立场与公共统计选择有效宽度，独立于正文更正；自动宽度和内部成员所需空间仍是下限。
- 归并、排列及追溯展开的分类、总结从内向外测量。每条引用、支持、反对关系在双方最近的共同容器内计算列：支持位于目标块左侧，引用与反对位于右侧；成员在外部布局中由其所属子框架整体参与避让，连线与统计仍指向原始成员。框内列只由框内关系决定，外部关系不能拉开内部成员；横向排列保留声明顺序。循环列约束压入同一列并纵向避让。
- 跨分类引用将来源分类整体放在目标分类右侧，引用分类本身和引用其成员使用同一规则；共同父框架原有的横排、纵排顺序不能覆盖这条分类间约束。所有生效的左右约束均参与计算，新增关系可沿已有关系链级联移动消息或框架；外部关系只平移框架，保留其内部相对布局。阅读顺序仍使用原讨论主树，其他引用补充位置约束，不因合并位置约束而混用不同讨论的作者列偏好。
- 部件和固定历史版本的引用不当作当前整条消息。更正提案在授权前只展示提案；已生效的内容从服务器新修订读取。
- 追溯范围按语义关系跳数向上、向下分别做广度搜索。同一有效排列的直接成员彼此相隔 1 跳，作为并列关联可在任一方向走这 1 跳；继续追溯成员的引用、回复等关系时仍遵循所选方向。排列消息与其直接成员也相隔 1 跳，嵌套排列逐层计算。归并、总结和分类只提供归属上下文，不通过容器到达其他成员；加入历史也不构成跳数。以单个展开的分类为起点时，当前层成员及内联归并、排列成员共同作为第 0 层消息，再计算各自的前因和后续；增加或减少距离都从这组起点重新计算，其他分类的同级成员不会被归属关系带入。调距时只保留所选分类的展开，重新补齐当前范围所需的祖先框架。
- 追溯阅读默认向上 1 层、向下 2 层，采用讨论主树的深度优先顺序：优先以回复、注释、引用、通知、赞同／反对确定主依赖，分支按时间及发布序号排列，循环只在排序主树中断开。可切换为使用同一主树逐层阅读的广度优先，或按时间从早到晚阅读；顺序切换保留当前消息、追溯距离、范围及已读记录，返回浏览现场恢复当时的顺序。范围内待阅正文与影响按目的消息合并成访问队列；额外关系保留影响任务，不重复展开整条分支。当前阅读组同时作为追溯起点；阅读单条、最近选中的整组及已读后的下一条时自动更新当前追溯，保留距离，不为逐条阅读新增追溯层。取消选中仍保留最近选择。后退、前进一起恢复实际浏览过的消息组与所在范围，不按队列顺序寻找邻居。“已读并继续”保存明确呈现的正文及影响后按阅读顺序推进，新出现的任务需单独纳入本轮。
- 字体、背景和光晕读取推荐投入；押注金额单独展示。
- 浏览、阅读和正文版本历史按视图配置复用最近场景；消息视图、阅读明细和关系明细共享缓存数量配置，默认 4 个。保留 4、8、12、20 个的配置和本地保存能力，暂不提供界面控件。缓存上限不参与场景身份计算，调整数量保留当前场景节点，按最近使用顺序淘汰超额旧场景。非当前场景及其浮窗从文档中移出，并挂起布局效果以释放观察器、定位监听和 Worker；当前场景重新接收实时消息、关系及阅读状态，等值布局输入复用已完成结果。导航计数只驱动定位，不再作为消息图的强制重建键；缓存不保存旧业务数据作为恢复来源，切换用户、范围或导出文件后释放。

跨框架有向边仅在两个连接端点都位于各自框架的可见窗口内时显示；隐藏时同时移除曲线、箭头及标签，避免端点被框内滚动隐藏后出现悬空半截连线。框内滚动或跳转重新显露端点后恢复连线，定位仍保留原始连接几何。

选择文字、来源与目标集合、框选、拖动、缩放、焦点、追溯和对比仍由原工作台入口操作。
