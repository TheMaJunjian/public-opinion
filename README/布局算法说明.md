# 非线性显示

`frontend/src/components/GraphView.tsx` 根据消息、关系和已生效状态生成显示，再由纯布局函数计算位置。

- `stanceLayout.ts` 按执行时解析的目标划分讨论区，赞同、目标、反对分列；保留原关系链供追溯。
- `frameLayout.ts` 从内向外计算组织尺寸，再从外向内放置。嵌套组织只测量和放置一次，循环引用不能造成无限递归。
- `useCardMeasurements.ts` 用稳定的 ResizeObserver 汇集真实卡片尺寸，尺寸不变时不触发布局更新。
- 分类、总结、归并、排列使用同一消息身份；当前被取消的覆盖效果恢复原消息，组织声明及历史仍可查看。
- 部件和固定历史版本的引用不当作当前整条消息。更正提案在授权前只展示提案；已生效的内容从服务器新修订读取。
- 字体、背景和光晕读取推荐投入；押注金额单独展示。

选择文字、来源与目标集合、框选、拖动、缩放、焦点、追溯和对比仍由原工作台入口操作。
