# 公论标准演示剧本

> 版本：v1.1  
> 日期：2026-07-31  
> 目标：~10 分钟演示公论核心闭环

---

## 准备

- 后端 `cd backend && npm run dev`（端口 3000）
- 前端 `cd frontend && npm run dev`（端口 5173）
- 数据库已迁移并含 seed 数据；若无，见 `README/重启后启动开发环境.md`

---

## 角色

| 角色 | 用户名 | 密码 |
|------|--------|------|
| Alice | alice | test123456 |
| Bob | bob | test123456 |

> 首次需在 `/register` 注册。后续从 `/login` 登录。

---

## 第一幕：进入议题（~1 分钟）

1. Alice 登录。首页自动打开议题「公论」。
2. 左侧为消息区，默认列表视图。可切换到图谱视图。
3. 右侧面板从上到下：结构概览、表态历史、审计日志、收入面板。

---

## 第二幕：发消息、建关系（~3 分钟）

### 发文本消息（Alice）
1. 右侧面板顶部输入框输入内容：
   > "太阳从东边升起。"
2. 点击发送（或 Ctrl+Enter）。消息出现在左侧列表。
3. 消息自动附带 `PRO` 自押（默认 10 点），另收 1 点手续费；可用积分减少 11 点。

### 创建议题（可选）
1. 若无议题，在 `/topics` 页点击「新建分类」，输入标题即可。

### 创建关系（Bob 反驳 Alice）
1. Bob 登录。
2. 左侧列表**点击 Alice 的消息**选中它。
3. 右侧「来源」区显示已选中。
4. 关系类型选 **DISAGREE**。输入内容："在地球另一端看，太阳从西边升起。"
5. 发送前确认预览中的自押金额和手续费，点击发送。
6. 结果：Bob 的反对关系消息出现在 Alice 消息附近。

### 赞同（Alice 换边）
1. Alice 登录。选中 Bob 的反对消息。
2. 关系类型选 **AGREE**。输入："有道理，观察位置确实影响结论。"
3. 发送。
4. 结果：Alice 的赞同关系消息叠加在 Bob 消息上。

---

## 第三幕：结算（~3 分钟）

### 发起结算
1. Alice **双击**自己的原始消息。
2. 弹出 SettlementPanel 悬浮层，显示该消息的押注池（赞同/反对各多少点）、已有轮次。
3. 若无活跃轮次，点击「发起结算」按钮，创建 TRUTH 结算轮次。
4. 第一轮进入 VOTING 状态。

### 投票
1. Bob 登录。双击同一消息。
2. 在 SettlementPanel 中选择投票方向（FALSE），输入点数，提交。投票会创建无文本 DISAGREE 关系消息并扣除投票金额和手续费。
3. Alice 创建无文本 AGREE 关系消息投 TRUE。
4. 权重实时更新。

### 关闭结算
1. 按当前 RuleVersion 的权限，允许的用户在 SettlementPanel 点击「结算」（seed 默认允许任何已登录用户）。
2. 结果公布。胜方获得收益、败方失去押注。

---

## 第四幕：推翻与追溯（~2 分钟）

### 发起第二轮推翻
1. 对同一消息再次双击，点击「发起结算」。
2. 新轮次自动关联前一轮。RoundHistory 面板以 `→` 箭头显示推翻链。

### 投票、关闭
1. 用户投票后关闭。新结果若与旧结果不同，触发 clawback（追回前轮胜方收益）。

### 查看账本
1. 点击顶栏积分余额，查看 LedgerEntry 列表：MINT（铸币）、LOCK（锁定）、EARN（收益）、LOST（损失）、CLAWBACK（追回）。

---

## 第五幕：审计与清爽视图（~1 分钟）

### 审计日志
1. 右侧面板「审计日志」区域展开。
2. 时间轴列表显示全部操作：消息创建、关系创建、押注、发起结算、投票、结算结果。
3. 每条记录含时间、操作类型标签、操作者。

### 清爽视图
1. 左侧消息区顶部工具栏，点击「清爽视图」。
2. 添加已支持的过滤规则，例如发送者、关系类型、押注额度或标签子类型。
3. 匹配的消息保留在当前投影中，不匹配的消息被过滤；原始数据不会删除。

## 已知限制

- 审计日志当前按议题范围展示，不支持按用户/轮次过滤（B6 改善）。
- 清爽视图当前主要是本地组合过滤器；标签统计 API 已存在，但公开持久化的视图规则和默认阈值策略仍待后续迭代。
- 清爽视图过滤器目前主要由前端组合；标签统计 API 已存在，但公开持久化的视图规则和默认阈值策略仍待后续迭代。
- 本剧本只演示当前可用流程，不代表完整去中心化节点或链上运行。
