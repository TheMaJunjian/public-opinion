## 一、项目摘要

楚门不是一个单一软件产品，而是一套可能覆盖信息、协作、财富分配和生活保障的全新社会运行方式。它的核心设想是：在公共场合公开行为，用透明换取信任，用信任降低交易成本，再把节省下来的资源用于成员的基础生活保障。

公论是楚门计划的第一块可运行拼图。它把线上文字交流做成开会：“讨论、投票、结算”，任何议题都可以被提出，参与者可以发言、站队、举证、质押和投票，胜利的一方获得贡献点，所有人共同留下可追溯、可复查、可持续修正的结果。

投资人今天投的不是一个讨论工具，而是一个从信息判断切入、逐步进入组织治理、商业交易和成员保障的长期基础设施。公论先证明“有价值的判断可以被记录、被结算、被分配”，再以此为基础建设楚门的透明协作网络。

**一句话：公论不是让人围观讨论，而是让人用贡献点为自己的判断下注，并为结果负责。**

## 二、投资人应该看到的终局

### 1. 从“刷屏互联网”走向“可结算的互联网”

今天的互联网擅长传播信息，却不擅长判断信息。聊天、评论和社交媒体让每个人都能说话，但没有把发言、证据、立场、责任和收益放进同一套可验证的机制里。结果是：噪音越多，真正有价值的判断越容易被淹没；用户贡献了内容、注意力和判断，平台却掌握了主要的分配权。

公论试图建立下一层互联网基础设施：

```text
发言 → 站队 → 举证 → 投票 → 结算 → 纠错 → 留下可复用的知识
```

每一次判断不再只是一次性表达，而是一项可以被检验、被追责、被复用的公共工作。最终形成的不是帖子堆，而是一座持续生长的“真理数据库”：结论可以被调用，证据可以被追溯，错误可以被定位，纠偏过程本身也成为后来者的知识。

### 2. 从“内容平台”走向“判断市场”

公论把信息价值交给参与者共同识别。发言需要消耗贡献点，高质量判断、有效证据、错误纠正和推动共识形成可以获得贡献点。用户不只是消费内容，也参与内容筛选、规则治理和收益分配。

这会改变传统平台的分配关系：

| 传统平台 | 公论设想 |
|---|---|
| 创作者生产内容 | 所有人都可以生产观点、证据和判断 |
| 用户贡献注意力 | 用户直接参与识别信息价值 |
| 平台决定推荐与分配 | 公开规则和参与者共同决定分配 |
| 错误内容沉入信息流 | 错误可以被挑战，纠正者获得回报 |
| 讨论结束后信息失效 | 结论持续存证，未来仍可调用和推翻 |

### 3. 从“互联网产品”走向“楚门公司”

公论解决的是楚门最先必须解决的问题：人们如何在不依赖身份、权威和黑箱管理员的情况下，共同判断什么有价值、谁做出了贡献、什么结果值得信任。

当判断、贡献和治理能够被公开记录，楚门才有可能进一步成为一种透明协作组织：成员可以在基础生活有保障的前提下，自愿选择工作、娱乐、创造和管理；地位不只由金钱或出身决定，也由可记录的贡献决定；组织收入不再只流向平台所有者，而可以按公开规则回流给参与者。

这不是当前已经兑现的生活保障承诺，而是公论一旦形成网络效应后，能够支撑的更大终局：**让现实拥有一个充值入口，让贡献能够换取地位，让透明能够换取自由，让游戏降临现实。**

## 三、我们要解决的问题

### 1. 信息越来越多，可靠共识越来越贵

- 观点、事实、证据和情绪混杂在同一信息流中。
- 传统平台依赖中心化推荐、管理员裁决和不可见的商业规则。
- 参与者可以轻易表达立场，却很少需要为立场承担可追溯的成本。
- 结论一旦形成，后续修正、翻案和责任追踪通常难以完成。

### 2. 协作中的信任成本很高

陌生人之间的交易、公共决策和团队协作，都需要付出大量验证、监督、协调和纠错成本。透明不是把所有信息无差别公开，而是让参与者能够在自愿、明确边界和可审计规则下验证关键行为。

### 3. 价值创造缺乏可复算的记录

有价值的工作不只发生在生产线上，也发生在发现问题、提供证据、识别错误、审计规则和推动共识修正的过程中。现有互联网产品很少把这些贡献统一记录，并让贡献者获得可解释的权重、声誉或收益。

## 四、产品与解决方案

公论是一个讨论、投票、结算的线上文字开会系统，不是开会模拟器，而是真的可以针对任何议题开会并形成结果。它提供结构化讨论、价值证明和协作分配：

```text
提出观点 → 建立关系 → 提供证据 → 公开表态与质押
    → 结算当前共识 → 后续复查或推翻 → 账本记录与收益分配
```

### 核心玩法

1. **提出议题**：发布文本消息，表达一个需要讨论和判断的观点。
2. **建立关系**：通过赞同、反对、标注、推荐、引用、回复、注释等关系，明确消息之间的结构。
3. **贡献立场**：发送消息和关系时消耗贡献点；每个贡献点既是成本，也是对立场的投票权。
4. **发起结算**：围绕消息投票，一点贡献点一票，多数方向获胜，胜方按比例分配败方贡献点。
5. **持续纠错**：结算结果不是永恒真理。新证据可以发起新一轮结算，推翻旧结果，相关贡献点按新结果重新分配。
6. **沉淀知识**：讨论过程、证据、错误、纠偏和最终状态都被保留，形成可检索、可复算、可复用的知识资产。

### 核心产品能力

| 能力 | 产品表现 | 解决的问题 |
|---|---|---|
| 线上文字开会 | 议题、发言、关系、投票和结算在同一空间完成 | 让任何议题都能形成可追溯结果 |
| 统一消息模型 | 文本、关系、结算、治理和代码变更均可记录为消息 | 让讨论、规则和执行处于同一条历史中 |
| 非线性讨论图谱 | 观点、支持、反对、引用、修正等关系可视化 | 保留讨论上下文，避免信息流把因果关系冲散 |
| 贡献点与质押 | 参与者为观点和立场锁定贡献点 | 让立场带有可验证的成本 |
| 结算与推翻 | 公开规则形成阶段性结果，后续轮次可推翻前轮结果 | 允许共识修正，而不是制造不可撤销的终局 |
| 治理迭代 | 治理提案经过讨论、质押、投票和结算后形成新规则 | 让规则本身也可被讨论和监督 |

## 六、为什么这不是 Polymarket 的复制品

Polymarket 把押注用于预测事件，公论把押注用于生产和筛选可持续使用的信息。两者都涉及“押注”和“结果”，但终点不同：

| Polymarket | 公论 |
|---|---|
| 事件结束，合约结算 | 讨论开始，知识持续积累 |
| 结果出来后信息价值快速归零 | 结论可以长期调用，成为知识库部件 |
| 一次定音 | 新证据可以持续挑战和推翻 |
| 主要是金融投机 | 主要是判断、纠错和知识生产 |
| 错误通常只意味着押错本金 | 纠错者可以获得押错者的筹码 |
| 零和博弈 | 每次纠错都可能增加社区可复用的信息资产 |

例如，用户讨论某商品是否为 316 不锈钢。商家可以为自己的商品押注，这份押注既是自我增信，也是质量保证金；如果后来有用户发现下一批商品并非 316 不锈钢，可以用证据发起挑战并获得相应回报。错误不再只是沉默成本，而成为推动质量改进和知识积累的燃料。

因此，Polymarket 更像事件预测市场；公论更像一个持续运行的“证道会堂”：让事实、观点、产品质量、组织提案和公共判断都接受公开检验。

## 七、产品定位与发展路径

### 近期：公论作为免费游戏和线上协作入口

公论首先以免费游戏的方式降低参与门槛。用户可以免费参与讨论、提供判断样本和观察结论；愿意充值的用户可以获得更多贡献点，并购买更高排行榜位置、更好的展示样式和高级功能体验。氪金用户为系统提供真实资源，零氪用户也不是单纯的免费体验者：他们提供讨论生态、背景样本和判断贡献，同样可以从有效参与中获得贡献点和回报。

这形成一个有机会自我增强的循环：

```text
充值与运营收入 → 奖励有效参与 → 更多人愿意参与判断
  → 更多高质量信息 → 更高使用价值 → 更多充值与组织使用
```

服务对象包括普通用户、内容与测评创作者、商家、研究团队、社区和协作组织。产品重点是让讨论结构化，让判断责任可追踪，让知识能够长期复用。

### 中期：开放协议、去中心化与收益分配

逐步开放主题导出、审计格式和 replay 工具，吸引第三方应用、社区和审计节点接入。公论的去中心化不是匿名逃避监督，而是把发行、结算、治理、收入分配和兑换规则公开化、可复算化，让任何参与者都可以验证系统状态，而不是只能相信平台后台。

去中心化的推进路径是：

```text
中心化可用产品 → 公开事件与审计导出 → 第三方 replay 复算
  → 独立审计节点 → 多方共同维护规则、账本和分配
```

提案消息可以参与手续费、充值收入和运营收入的分配规则设计；用户不只参与内容生产，也参与游戏运营和收益分配。应用可以围绕知识协作、商品测评、组织治理、研究判断、内容质量和贡献分配构建。

### 长期：楚门透明生存体系

在公论形成的公开判断、贡献记录和治理基础上，楚门将继续探索一种成员自愿加入、公共行为透明、成员能够获得基础生活保障的新型跨国公司。成员可以选择不工作，也可以为了更好的生活、兴趣和地位自愿工作；贡献由系统记录，地位由贡献积累，组织管理接受所有成员监督。

楚门的远期图景不是让所有人变得一样，而是让基础生存不再迫使人接受不喜欢的工作，让人可以把时间投入到娱乐、创造、照顾他人和真正愿意做的事情上。公论负责判断和分配，楚门负责把这种机制扩展到真实生活。

## 八、商业模式

公论的商业模式不是单一的广告平台，也不是单纯的金融手续费平台，而是由“游戏收入、组织服务、协议生态”逐层展开：

1. **游戏内充值与增值服务**：用户充值获得更多贡献点，并购买排行榜位置、展示样式和高级功能。贡献点不是单纯消费道具，而是参与判断、治理和结算的行动资源。
2. **运营收入分配**：充值和运营收入的一部分进入公开规则管理的收入池，按照提案、结算和治理结果，分配给有效参与者及生态贡献者。


核心飞轮是：氪金用户提供资源，零氪用户提供参与密度，优秀参与者获得回报，更多用户因此愿意参与；参与越多，知识资产和判断质量越高，公论对个人、组织的价值越高，最终形成持续的充值、服务和生态收入。

### 贡献点与充值货币的经济闭环

贡献点不是只能在系统内部消耗的一次性积分，而是公论用来记录有效贡献、表达判断权重、参与治理、参与结算和获得分红的核心资产。用户可以通过充值获得初始贡献点，也可以通过发言、举证、纠错、审计、治理和其他有效贡献获得贡献点。

当平台产生充值收入、服务收入和生态运营收入后，按公开规则将可分配部分进入收入池。贡献点持有者和有效贡献者按照贡献点数量、贡献质量、治理结果及其他公开参数参与分红；分红所得可以按系统规则兑换回充值货币，或继续兑换为贡献点，用于继续参与讨论、投票、治理和消费增值服务。

```text
充值货币 → 贡献点 → 发言/举证/投票/治理/纠错
  → 形成可复用信息与组织价值 → 收入进入收入池
  → 按公开规则分红 → 贡献点兑换回充值货币
```

这使公论区别于普通内容平台：用户不是只贡献内容和注意力，平台也不是唯一的价值分配者。用户参与生产信息、识别价值和维护规则，并依照公开规则分享由整个系统创造的收入。去中心化的意义，正是让这套发行、结算、分红和兑换机制逐步摆脱单一平台的任意控制。

贡献点的发行、分红、兑换比例、兑换条件和收入池规则都必须公开记录、可审计、可治理，不能由运营方临时修改。贡献点是否可以兑换、兑换为哪一种充值货币、是否设置锁定期和额度限制，以正式产品规则、运营主体资质和法律意见为准；任何面向公众的充值、兑换、分配和跨境业务，都需要在正式推出前完成法律、财务和监管评估。

## 九、竞争优势与护城河

### 1. 从“内容平台”转向“可验证判断平台”

公论的核心不是增加一个信息流，而是把观点、关系、证据、成本、结算和历史绑定在一起，形成可复查的判断基础设施。

### 2. 结果可变，但历史不可被悄悄抹除

系统允许新一轮结算推翻旧结果，同时保留前轮记录、冲销分录和责任链。它既避免把一次投票伪装成永恒真理，也避免修改历史后无人知晓。

### 3. 规则也接受规则化监督

治理提案、规则版本和代码变更可以进入同一套讨论、质押、投票和审计流程，降低“平台规则由少数人黑箱决定”的风险。

### 4. 开放源码与渐进式去中心化路线

项目源码公开，当前先以可运行的中心化版本验证产品和机制，再逐步推进公开复算、独立审计节点和关键状态上链。技术路线遵循“先验证价值，再增加复杂度”。

## 十、市场与切入场景

项目首批切入场景不追求一次覆盖所有社会问题，而聚焦于高争议、高协作、高审计需求的领域：

- 研究和事实核查：记录主张、证据、反驳和结论修正。
- 社区与组织治理：提案、讨论、投票、执行和复盘留痕。
- 专业协作：把问题发现、评审、知识贡献和责任链结构化。
- 公共议题讨论：降低信息噪音，提高证据和立场的可追溯性。

市场规模将以首批客户访谈、付费试点和实际留存数据逐步验证，不在当前阶段用宏大人口数字替代商业验证。

本项目本轮寻求的不是单纯财务投资，而是能够“出钱，也能出人、出资源”的战略合作方。马军健已经完成核心构想、产品原型和机制设计，但项目要从原型进入真实用户、持续运营和商业化阶段，必须引入具备相关经验的专业团队。

投资人可以通过以下方式参与：

- **资金投入**：支持产品完善、公测、用户运营、合规建设和核心团队招聘。
- **人才投入**：推荐、派驻或共同招募用户运营、增长、商业化、组织管理、技术安全和财务合规负责人。
- **业务资源投入**：引荐首批社区、企业、研究机构、商家和试点组织，帮助验证公论的真实使用场景。
- **管理支持**：协助建立招聘、预算、目标管理、财务、法务和公司治理制度。

其中，投资人提供的核心人才可以作为正式员工、联合创始人、事业部负责人、驻场负责人或长期顾问参与，具体合作形式根据投入时间、职责范围和双方协议确定。资金和人才投入将共同纳入融资、股权、期权、顾问权益或其他合法合作安排的谈判，不预先虚构具体比例。

### 资金与资源用途建议

| 方向 | 建议占比 | 具体用途 |
|---|---:|---|
| 产品与工程 | 40%-50% | 稳定性、权限、安全、审计导出、移动端和协作体验 |
| 公测与客户验证 | 20%-25% | 服务器、试点组织、用户研究、运营和内容建设 |
| 合规与安全 | 15%-20% | 法律论证、隐私边界、数据安全、财务与审计制度 |
| 团队与行政 | 20%-30% | 核心成员、用户运营、商业化、外部顾问和基础运营成本 |

除现金预算外，本轮还需要投资人协助提供关键岗位候选人、行业顾问和首批试点资源。对于投资人能够直接提供的团队成员和业务资源，将减少相应现金招聘与获客成本，并加快项目从原型走向真实运营。

### 本轮里程碑

1. 建立稳定公网公测环境，完成首批真实用户和组织试点。
2. 将审计导出、replay/verify 和规则版本做成第三方可使用的标准工具链。
3. 验证至少一个可付费的组织版或审计服务场景。
4. 完成独立安全审查、隐私边界设计和商业合规评估。
5. 建立核心团队，形成产品、后端协议、用户运营、商业化、安全合规和组织管理的基本能力。

## 十二、团队与创始人

### 马军健｜发起人

马军健提出楚门的公开透明生存体系构想，并持续公开发布项目理念、产品设计、技术实现和运营设想。当前仓库由其维护，项目从理念文档逐步推进到可运行的软件协议原型。

马军健当前最明确的能力优势，是提出楚门和公论的整体构想，完成产品原型，设计贡献点、结算、分红和去中心化路线，并持续推进下一阶段功能设计。目前缺少将项目规模化运营所需的成熟团队和相关实践能力，尤其需要补齐用户增长、社区运营、商业化、组织管理、财务和合规等方面的能力。

本轮融资要解决的核心问题：把一个由创始人主导的原型项目，建设成拥有完整执行能力的产品公司。创始人负责长期方向、核心机制、产品判断和技术路线；专业团队负责把方向转化为用户、收入、组织和合规结果。

### 融资后的配团队计划

| 岗位 | 首要任务 | 引入方式 |
|---|---|---|
| 产品与技术负责人 | 把现有原型稳定化，完善移动端、权限、安全、审计和贡献点经济系统 | 核心全职成员 |
| 用户与社区运营负责人 | 建立首批用户群，组织议题和线上活动，提升留存、活跃与有效讨论密度 | 核心全职成员 |
| 商业化与增长负责人 | 验证充值、增值服务、组织版订阅和付费试点，建立收入模型 | 核心全职成员或合伙人 |
| 组织与项目运营负责人 | 负责招聘、流程、目标管理、合作伙伴和日常交付 | 核心全职成员或早期 COO |
| 法律、财务与合规顾问 | 评估充值、分红、兑换、数据公开、跨境和成员权益等风险 | 外部顾问起步，必要时转长期岗位 |

团队建设顺序是先补齐“能把产品推向真实用户”的运营和商业化能力，再扩充工程、安全和去中心化基础设施能力。具体人数、薪酬和股权安排将在融资规模、候选人质量和尽调结果确定后制定，不在当前 BP 中虚构已存在的团队履历。

## 十三、主要风险与应对

| 风险 | 具体表现 | 当前应对 |
|---|---|---|
| 产品教育成本 | 质押、结算和推翻机制比普通信息流复杂 | 先用单一场景和标准演示验证，再逐步开放高级能力 |
| 网络效应冷启动 | 没有参与者就没有高质量共识 | 从组织版、研究协作和小型社区切入，先形成高密度场景 |
| 经济模型风险 | 贡献点和收益分配可能引发投机或误解 | 所有规则公开可复算，不作收益承诺，逐步进行法律评估 |
| 隐私与安全 | 透明边界、身份信息和公开记录需要谨慎设计 | 明确公共场合与私密空间边界，实施最小化收集和安全审计 |
| 治理风险 | 公开投票不自动等于正确或公平 | 保留证据、成本、历史和推翻机制，允许规则持续修正 |
| 愿景兑现风险 | 楚门长期保障目标远大于当前产品阶段 | 对外明确区分产品事实、实验假设和长期愿景，以里程碑推进 |
| 团队能力风险 | 创始人具备方向、原型和机制设计能力，但规模化运营与商业化团队尚未配齐 | 将融资的一部分明确用于招募运营、增长、商业化、组织管理和合规人才，并以用户、收入和交付里程碑检验补团队效果 |
| 监管与合规 | 支付、分配、跨境和成员权益可能触及不同法规 | 任何相关功能上线前完成专业法律意见和合规审查 |

## 十五、对投资机构的沟通重点

我们希望寻找的不只是资金，而是能够理解长期社会基础设施、开放协议和耐心产品验证的合作方。资金将优先用于把公论从“可运行原型”推进到“真实组织愿意持续使用、愿意付费、能够被第三方审计”的产品，并以公开、可验证的里程碑持续汇报进展。

本 BP 中“楚门成员基础保障”等内容属于长期愿景和待验证的组织实验，不构成收益承诺、证券发行、募资邀约或对项目未来结果的保证。正式投资、股权、可转债或其他融资安排，以双方签署的法律文件和专业机构意见为准。
