# 开发环境

需要 Node.js 24 或更新版本。在仓库根目录执行：

```powershell
npm ci
npm run dev
```

浏览器访问 http://localhost:5173；API 监听 http://127.0.0.1:3000。
数据库在首次启动时自动建立于 `data/gonglun.sqlite`。开发环境可以直接注册，首位用户成为发起人。

`Ctrl+C` 结束开发服务；下次执行同一命令即可继续使用原数据。也可以运行 `deploy/start.ps1`。

生产构建：

```powershell
npm run build
npm start
```

构建后的页面和 API 均由 3000 端口提供。通过 `GONGLUN_DB` 指定另一份 SQLite 数据库；数据文件、WAL 和 SHM 文件属于同一运行数据库，不要在运行时单独复制主文件作为备份。
