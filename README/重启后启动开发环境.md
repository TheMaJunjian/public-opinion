# 电脑重启后，如何启动前后端开发环境

本项目的后端（Express + Prisma + PostgreSQL）和前端（Vite + React）需要按以下顺序启动。

---

## 前提条件

- 已安装 [Docker Desktop](https://www.docker.com/products/docker-desktop/)（用于运行 PostgreSQL）
- 已安装 [Node.js](https://nodejs.org/) 20+
- 依赖已安装过（`node_modules` 存在），否则先执行 `npm install`

---

## 步骤一：启动 PostgreSQL 数据库

打开一个终端，进入 `backend` 目录，启动 Docker 容器：

```powershell
cd d:\Projects\public-opinion\backend
docker-compose up -d
```

> 如果 Docker Desktop 还没启动，先打开 Docker Desktop，等它状态变为 "Engine running" 后再执行上面的命令。

验证数据库是否就绪（可选）：

```powershell
docker-compose ps
```

看到 `postgres` 服务状态为 `Up` 即可。

docker-compose stop api

然后再 npm run dev 就不会端口冲突了。之后每次重启只需：
做什么	命令
启动数据库	docker-compose up -d postgres
启动后端	npm run dev
启动前端	npm run dev（在 frontend 目录）


---

## 步骤二：启动后端开发服务器

在同一个终端（或新开一个），确保在 `backend` 目录：

```powershell
cd d:\Projects\public-opinion\backend

# 如果重启后第一次运行，确保数据库迁移是最新的（可选但推荐）
npm run db:migrate

# 启动后端开发服务器（端口 3000）
npm run dev
```

看到类似以下输出表示成功：

```
Server is running on http://localhost:3000
```

> Swagger 文档地址：http://localhost:3000/api-docs

---

## 步骤三：启动前端开发服务器

**新开一个终端**（不要关掉后端），进入 `frontend` 目录：

```powershell
cd d:\Projects\public-opinion\frontend

# 启动前端开发服务器（默认端口 5173）
npm run dev
```

看到类似以下输出表示成功：

```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

---

## 步骤四：打开浏览器访问

浏览器打开 http://localhost:5173/ 即可使用。

前端会自动将 `/api` 请求代理到后端 `http://localhost:3000`，无需额外配置。

---

## 快速汇总（一次性操作）

在 VS Code 中打开三个终端，分别执行：

| 终端 | 目录 | 命令 |
|------|------|------|
| 终端 1 | `backend` | `docker-compose up -d` |
| | | `npm run dev` |
| 终端 2 | `frontend` | `npm run dev` |
| 终端 3 | 任意 | 打开浏览器访问 http://localhost:5173 |

## 常见问题

### Q: Docker Desktop 卡在 "Starting the Docker Engine..."
A: 这是 Windows 上常见问题，通常是 WSL2 没响应。按顺序执行：
```powershell
# 1. 关闭 WSL
wsl --shutdown

# 2. 杀掉 Docker 残留进程
taskkill /F /IM "Docker Desktop.exe"
taskkill /F /IM "com.docker.backend.exe"

# 3. 重新打开 Docker Desktop
```
如果还不行，尝试更新 WSL：`wsl --update`，然后重复以上步骤。

### Q: 提示 `docker: command not found`
A: Docker Desktop 没有启动，先打开 Docker Desktop，等待引擎就绪。

### Q: 后端报数据库连接错误
A: 确认 PostgreSQL 容器正在运行：`docker-compose ps`。如果未运行，执行 `docker-compose up -d`。等待几秒后再 `npm run dev`。

### Q: 端口被占用
A: 检查是否已有进程占用 3000 或 5173 端口：
```powershell
netstat -ano | findstr :3000
netstat -ano | findstr :5173
```
如果有残留进程，用 `taskkill /PID <PID> /F` 结束它。

### Q: 前端页面空白 / API 报错
A: 确保后端先启动成功，前端通过 Vite 代理转发 `/api` 到 `localhost:3000`，后端未就绪时 API 请求会失败。
