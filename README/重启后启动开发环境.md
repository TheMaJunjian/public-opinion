# 开发环境

需要 Node.js 24 或更新版本，以及已启动的 Docker。首次运行时将 `.env.example` 复制为 `.env`；已有 `.env` 则保留并配置其中的 `DATABASE_URL`。在仓库根目录执行：

```powershell
npm ci
npm run dev
```

脚本先启动 PostgreSQL 16 并等待健康检查，再启动 API 和前端。浏览器访问 http://localhost:5173；API 监听 http://127.0.0.1:3000。数据库地址为 `postgresql://gonglun:gonglun_dev@127.0.0.1:54329/gonglun`，只向本机开放，数据保存在 Docker 卷 `gonglun-dev_postgres_data` 中。首次连接会自动建表，开发环境可以直接注册，首位用户成为发起人。

`Ctrl+C` 结束 API 和前端服务，数据库继续运行；下次执行同一命令即可继续使用数据。也可以运行 `deploy/start.ps1`。单独启动或停止本地数据库：

```powershell
node scripts/postgres.mjs
docker compose -f deploy/docker-compose.dev.yml stop postgres
```

已有 PostgreSQL 时，将连接地址写入根目录 `.env` 的 `DATABASE_URL`，或在 PowerShell 设置 `$env:DATABASE_URL`。开发脚本会连接指定的数据库，不再启动默认数据库容器。数据库需要提前创建，账号需要在该数据库内建表的权限；示例变量见 `.env.example`。

生产构建在同一个数据库上运行：

```powershell
npm run build
npm start
```

构建后的页面和 API 均由 3000 端口提供。`npm start` 需要数据库已运行；服务器部署和数据库备份见 [服务器部署](云服务器部署.md)。
