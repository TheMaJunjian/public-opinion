# 本地文件阅览

公论以消息、证据、表态和组织讨论为主要功能。知乎导出程序及本机文件阅览仅是用户可选的本地辅助，不上传文件、不发布为公论消息。首页以公论为主，本机阅览保持为次要入口；相关选项与同步详情默认折叠。

新版 [personal-data-exporter](https://github.com/TheMaJunjian/personal-data-exporter) 在所有目录统一导出精简 `gonglun-view-3` v5。正文只存于 `parts`，读取时从部件还原界面需要的 `content`，不再重复保存。`gonglun.json` 不附带整份 `zhihu.archive`、旧 `overrides` 或 `localOperations`；保留消息、作者、时间、关系和少量来源身份信息。

从导航栏“阅览”或首页下方“阅览本机文件”选择 JSON 即可打开。精简文件仍按来源识别为知乎文档阅览，可使用线性、非线性视图，并在本机发送回复、赞反、更正及组织消息；操作保存为公论原生消息，不把旧来源封装写回文件。

“下载阅览文件”可生成独立快照，也可选择以前下载的精简阅览文件，点击“更新文件”合并当前原文和本地原生消息，再保存到原文件。重复更新不重复添加消息，兼容的较长本地消息历史会保留；不同来源、缺失原文或本地历史分叉会停止合并。保存前还会核对目标文件与所选旧文件是否一致。此过程完全在本机完成；单个 JSON 会完整写回，按新增内容追加保存使用下方的目录关联。

在 Chrome 或 Edge 的“阅览”中展开“本地辅助”，选择“关联知乎导出目录”，可持续读取该目录的 `gonglun.json`。本人作品和收藏应分别关联各自目录，收藏选择 `collections`。在前台每 5 秒或切回页面时检查更新；已打开文档和折叠状态沿用同一份本机缓存，更新失败保留当前视图。本地新增内容以原生消息增量追加到同目录的 `gonglun-local.ndjson`，格式为 `gonglun-native-messages`，不使用旧的 `overrides` 或 `localOperations` 日志。重新导出原始资料后，这些本地原生消息继续合并保留；旧日志不会被当作新消息自动迁移。

导出器的增量采集、续传继续使用 `checkpoint.json`、`checkpoint.journal.ndjson` 和原始采集档案；这些采集资料独立于精简阅览文件，不要只凭 `gonglun.json` 恢复采集任务。

已有知乎导出可在导出器的 `platforms/zhihu` 目录运行：

```sh
npm run migrate:view -- /path/to/gonglun.json --in-place
```

脚本只处理指定阅览文件，原地删除旧来源封装和重复正文；不处理采集检查点，不请求网络。省略 `--in-place` 会另存 `.compact.json`，可选输出路径不会覆盖已有文件。

已放弃的旧知乎整理缓存会在新版首次打开阅览缓存时清除，包括旧目录关联和折叠状态；普通公论文件缓存保留。需要时重新关联目录即可。旧版原始归档或整理文件仍能直接读取，但不迁移此前浏览器中的知乎整理记录。

正式构建会准备离线界面。阅览窗口显示“离线可用”后，断网仍能重新打开本站及本机文件。清除网站数据会移除离线缓存和本机阅览记录，磁盘文件不受影响。离线功能需要 HTTPS 或 localhost，开发服务器不启用。
