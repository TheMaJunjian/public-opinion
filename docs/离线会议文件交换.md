# 几台电脑在同一局域网开会

每台电脑各自打开公论。大家通过一个共同可读写的文件夹收发文字和回复，开会期间无需连接公论服务器。

## 会前准备

1. 在一台开会期间保持开机的电脑或局域网文件服务器上共享一个文件夹，给参会者读写权限。假设共享电脑名为 `MEETING-PC`，发起人可以选择本机的 `D:\会议`，其他电脑选择指向它的 `\\MEETING-PC\会议`。会前确认每台电脑都能在同一个目录里看到和新建文件。[Windows 局域网文件夹共享步骤](https://support.microsoft.com/zh-cn/windows/experience/connectivity-networking/file-sharing-over-a-network-in-windows)
2. 每台电脑用支持目录读写的浏览器打开公论正式版。如果开会时没有互联网，请提前打开首页的“阅览”，等到显示“离线可用”。[Chrome 文件系统访问说明](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access?hl=zh-cn)

## 创建和加入

1. **发起人**在首页点“阅览 → 共享文件夹会议”，选好共享文件夹，填写会议名称，点“创建并进入”。
2. **其他人**从各自电脑打开同一入口，选择同一个共享文件夹，点会议名加入。如果选择目录时发起人还在创建，点“刷新会议列表”。同一目录可以开多场会，同名时可用创建时间和编号区分。
3. 每个人在右侧“本地发言人”填写自己的署名，即可同时打字、发言和回复整条发言。署名由本人填写，离线会议不结算贡献点。

## 同步和归档

进入后，“会议交换 · 自动”表示这台电脑已连接目录。发言先存入本机并立即触发同步。会议页面在前台时，每轮检查结束约半秒后再检查一次，切回页面时立即检查。实际送达时间取决于共享盘的读写速度。

共享盘断开时仍可在本机发言。恢复后，打开的会议会自动重试。若浏览器收回读写权限，可在“会议交换”点“立即同步”重新授权。关掉会议再加入时，用同一浏览器从“共享文件夹会议”选择原目录和会议，可接着同步本机已保存的发言。

会后先让各台电脑完成最后一次同步，再在归档电脑的“会议交换”点“立即同步”。确认成功后，点“下载阅览文件”保存整场记录。会议目录内的文件含可读正文，有权读取目录的人可以保存和转发发言。

## 已有议程或手动交换

如需用已有本地文字作为议程，可打开普通本地消息文件，在“会议交换”点“生成会议起始文件”。把下载的原名文件放入共享目录，成员即可从“共享文件夹会议”的列表加入。每次生成都会创建新的会议编号，全组应使用同一份起始文件。

如果没有共同可写的目录，或浏览器不支持目录读写，每人也可以从“阅览”打开同一份起始文件。在“会议交换”点“导出累计增量”，用 U 盘等方式交给其他人，再点“导入他人的会议增量”。重复导入会自动去重，会后归档前请收齐每位成员的最后一份增量。
