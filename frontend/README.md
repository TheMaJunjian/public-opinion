# 公论前端

React 工作台，保留文字选择、候选、来源、目标、关系工具栏和固定输入区的操作方式。

在仓库根目录安装和启动：

```sh
npm ci
npm run dev
```

消息和关系引用 `@gonglun/core` 模型。一次发送通过 `/api/ui/commands` 原子提交；`/api/ui/snapshot` 批量加载和按执行序号同步，`/api/events` 通知新变更。

显示以服务器已生效状态为准。直接选择消息卡上的正文、关系标签和成员数量。单击卡片选择整条消息，双击文本启用文字选择，双击分类进入；分类和总结的文字可以直接拖选。

```sh
npm test
npm run build
```
