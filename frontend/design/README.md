# 公论 A / B：局部设计样稿

Vite 开发服务器运行后打开 `/design/opus-paper.html`。这是独立预览页，不接入应用路由、不进入主入口构建，也不访问账户、接口或本地存储。

顶部可切换 A「案卷·印信」与 B「议事厅·卡牌」。A 延续 Opus 的暖纸方向，本轮补充真实装饰；B 依据 Opus 的深色卡牌方向，由 GPT 实现。切换只改变外观，不重建 DOM，不清空选择、折叠、等级或输入。正式界面的原 GPT 深色仍保留。

## 验证范围

- 真实装饰与折叠（默认）：赞同／反对、标注、更正三类，分别示范正文、关系标签、分类框架、标注消息四种宿主。赞反与标注独立折叠，标注上的赞反另有独立折叠；更正对比和历史始终保留。
- 赞反图标演示快速发送；数字区选中，双击或 ↗ 查看临时分类。标注单击选中，双击或“记录”打开临时分类。更正单击对比、双击历史，另有显式按钮。单击与双击分离，双击不会触发快速发送。
- 装饰选择接入样稿右侧候选暂存区；清空和移除同步取消选中。折叠或切换 A/B 不改变选择。正文对比、有效性和记录均为静态示例。
- 载体与等级：四种载体 × 四个等级，共 16 格。可阅读内容是纸片 / 表行；关系是带标签和箭头的实际路径；装饰附着于宿主；框架包含可折叠成员。不会把所有类型都做成卡片。
- L0 素纸、L1 压边、L2 洒金、L3 鎏金装裱采用轮廓、边框、角花、材质的静态差异。有向边线宽依次为 1 / 2 / 3 / 5，装裱边另有宽度。等级全部手动指定，不推断业务阈值或最终价值结论。
- B 的四级为素面 / 精工 / 辉光 / 星铸：中性细边、蓝色金属、紫色双层辉光、金色装甲包角。粒子沿边缘短暂播放，正文保持稳定深底亮字。正反色只用于赞反操作和态势，不表示价值高低或胜负。
- 混合消息图：A01 → A02、A03 → A04、A02 → A04 三条边；D1 附着 A01；C1 内嵌 C2。点击对象或用下拉框选择，可单独改等级；折叠框架时连线接到可见祖先边界，保留真实端点标识。同一收起框架内的关系隐藏。
- 选中、片段、定位、推荐和正反态势可独立叠加；去色检验用于检查差异是否只依赖颜色。推荐只改变字号 / 层次，价值等级改变外缘材质；正文始终保持高对比度。
- 升级演示 900ms，降级 200ms，同时最多 4 个；视口外、系统或手动减少动效、密集模式均使用静态结果。密集模式增加四条成员，是视觉示例，不是性能压测。
- 普通浏览：420px 侧台、现有 16 种关系全部可见、候选与来源/目标操作入口。
- 状态叠加：整条/片段选择、当前定位、已阅、推荐层级与正反比例可以独立调整；推荐显著性使用现有消息正文，不假设存在标题。
- 分类框架：两层分类的折叠、展开、进入入口；完全展开直接可见。
- 普通浏览场景的同一组消息可以切换表/图；引用箭头从 A028 指向 A027。
- 相关消息弹窗验证关闭按钮留白与文字清晰度。

配色直接引用 `src/theme/opus.css`，样稿布局和交互在此目录隔离。`opus-carriers.css/js` 为载体与等级对照，替换了旧的八张卡片式预览。正式接入时复用现有业务组件，不复制这里的示例状态管理。

## 后续设计修改位置

- `decoration-study.css`：装饰结构与 A 的三类外观、L0–L3、折叠入口。
- `gpt-arena.css`：B 专用外观、卡牌、边、徽章、框架、弹窗及粒子；不会覆盖正式 GPT CSS。
- `opus-carriers.css`：A 的四种载体与等级。
- `decoration-study.js`：共享装饰交互、样例宿主、记录和对比窗口。
- `study-theme.js`：预览 A/B 切换、等级名称、粒子装饰。`opus-paper.js` 仍管理共享候选、来源、目标和其他原有场景。

让 Opus 修改 A 时，只需审阅 A 外观和截图，不必重新生成整页。保留现有事件、折叠分组与操作入口；不要替换 B 专用样式。若造型改变尺寸，需重新核对连线、点击区与装饰避让。

## 尚未定义的业务语义

关系分组仅为显示分组；关系标识保留 `ALL_RELATION_TYPES` 的 16 项。价值等级阈值、押注五格阈值、正反比例统计口径、推荐分级均未定义。类型到载体的具体映射和每个类型的独特轮廓尚待结合真实组件确认，本轮验证载体和等级。费用、发送条件与集合操作是静态示例，不能替换生产校验。分类框的虚实边框、阅读位置、容器尺寸和其他状态，正式实现时仍以现有语义为准。

定位、推荐增加、价值外缘展示一次性动效；遵循系统减少动效设置，也可手动关闭。演示发送不会发布消息或扣费。
